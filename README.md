# camo — 光学迷彩ディスプレイ

タブレット/スマホの背面カメラ映像を、正面の観察者から見て「端末の向こうが透けて見える」
ように補正して表示するWebアプリ(単一HTMLファイル、外部ライブラリ不要)。

## 使い方(Android Chrome)

GitHub Pagesで公開しているので、Android Chromeで以下のURLを開くだけで使えます。

https://sintaryota.github.io/camo/

1. 上記URLを開き、カメラ利用を許可する
2. 右上の歯車アイコンから設定パネルを開き、以下を実測値に合わせて調整
   - 横幅 w: 実際に表示している映像エリアの横幅(cm)
   - d1: 観察者の目〜画面の距離(cm)
   - d2: 画面〜背景の距離(cm)
   - FOV: 背面カメラの水平画角(度)。「FOV較正モード」で既知の幅の物を使って実測可能
3. 必要ならチルト角度・オフセットでカメラの取り付け位置のズレを補正
4. 歯車アイコンでパネルを隠すと全画面表示になる

前面カメラでの顔検出によるd1自動推定にも対応(対応端末のみ、実験的機能)。

## ローカルファイルとして開く場合

ダウンロードした `index.html` を `file:///sdcard/Download/index.html` のように
Chromeのアドレス欄に直接入力して開いてください。ファイルマネージャーからのタップ
(`content://...`)では安全なコンテキストと見なされずカメラ許可が出ません。
